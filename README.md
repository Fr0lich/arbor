# Museum Object Visualizer

A python program to visualize a database of museum objects which is stored in Excel and allow the user to edit and review the data in the database.

## Prerequisites

Make sure you have Python installed. You can install all project dependencies using:

`ash
pip install -r requirements.txt
`

## How to Run

To run the application:

`ash
python main.py
`

## Creating an Executable (.exe)

To build a standalone executable for Windows, run:

`atch
build_exe.bat
`
