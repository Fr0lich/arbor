# Agent Guidelines for Arbor

This file contains important information and guidelines for AI agents working on the Arbor project.

## Agent Documentation

When working on this repository, please review the relevant documentation files located in the `documentation/agent/` folder before making any changes.

Important guides include:
- **`documentation/agent/MOBILE_COMPANION_GUIDE.md`**: **CRITICAL** - You must read this file before making any changes to the mobile companion app or its backend server (`mobile_server.py`). It contains strict rules regarding frontend implementation, logic syncing, and performance.
- **`documentation/agent/AI_UI_GUIDE.md`**: Contains color palette and UI guidelines.
- **`documentation/agent/CLAUDE_BUG_REVIEW_GUIDE.md`**: A focused guide for Claude and AI agents to efficiently review the codebase, specifically targeting performance bottlenecks, structural issues, and concurrency/threading bugs.
- **`documentation/agent/CODE_REVIEW.md`**: Contains information on prior code reviews and optimizations.
- **`documentation/agent/codebase_guide.md`**: Provides a high-level architecture map of the Tkinter desktop app.
- **`documentation/agent/feature_catalog.md`**: Lists core features of the desktop app.

## General Rules
- Read and adhere to the guidelines presented in the specific documentation files linked above according to the task you are performing.
- For mobile companion tasks, the `MOBILE_COMPANION_GUIDE.md` is strictly enforced.
